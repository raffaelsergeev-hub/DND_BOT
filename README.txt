# 🎲 AI RPG Telegram Bot (D&D Master)

Асинхронный Telegram-бот для проведения бесконечных текстовых ролевых игр (RPG), где роль Мастера Игры (DM) исполняет нейросеть **Llama 3.1** (через OpenRouter API). В боте реализована классическая механика настольных игр — автоматический бросок кубика **d20** на каждое действие игрока, влияющий на развитие сюжета.

## 🚀 Основные фичи
* **Динамический сюжет:** Нейросеть генерирует сочное описание мира, реагирует на любые действия игрока и сама определяет сложность проверок на основе кубика.
* **Механика d20:** Автоматические броски кубика (от 1 — критический провал, до 20 — легендарный успех), которые напрямую передаются в контекст модели.
* **Изоляция и память пользователей:** Каждый игрок ведет свою независимую сессию. История ходов сохраняется в БД.
* **Защита от спама (Anti-Race Condition):** Использование асинхронных блокировок (`asyncio.Lock`) предотвращает перемешивание контекста при быстрой отправке нескольких сообщений.
* **Безопасный рендеринг:** Текст от ИИ очищается от ломающих тегов и преобразуется из Markdown в валидный Telegram HTML без риска падения бота.

## 🛠 Стек технологий
* **Язык:** Python 3.10+
* **Фреймворк:** [aiogram 3.x](https://github.com) (Asynchronous Telegram Bot API)
* **Интеграция ИИ:** [OpenAI SDK](https://github.com) (модель `meta-llama/llama-3.1-8b-instruct:free` через OpenRouter)
* **База данных:** SQLite + [aiosqlite](https://github.com) (полностью асинхронное взаимодействие)

## 📦 Локальная установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd YOUR_REPOSITORY_NAME
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию:**
   Создайте файл `TOKEN.py` в корневой папке проекта и добавьте туда ваши ключи:
   ```python
   BOT_TOKEN = "ВАШ_ТЕЛЕГРАМ_ТОКЕН_ОТ_BOTFATHER"
   AI_TOKEN = "ВАШ_API_КЛЮЧ_OPENROUTER_ИЛИ_PROXYAPI"
   ```

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## 📂 Структура проекта
* `main.py` — основной файл бота, инициализация клиентов, хендлеры и логика игры.
* `rpg_game.db` — локальная база данных SQLite (создается автоматически при первом запуске).
* `TOKEN.py` — приватные ключи конфигурации (добавлен в `.gitignore`).
* `requirements.txt` — список зависимостей проекта.
